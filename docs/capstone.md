# 结课项目指南

## 目标

不是再实现一个模型，而是完整回答一个应用问题：在明确的数据、精度和查询需求下，算子学习是否提供了有价值的替代方案？

## 推荐选题

- 二维 Darcy：渗透率场到压力场；
- Burgers：初值到未来轨迹；
- 热方程：初值/热源到温度场；
- 结构力学：材料或几何到位移/应力；
- 控制：状态轨迹到控制增益或闭环响应；
- 经济动力系统：外生路径或状态分布到政策/价值函数。

## 项目提案模板

1. 应用背景与未来查询方式；
2. 目标算子、输入空间和输出空间；
3. PDE/ODE、边界和初值；
4. 数据来源、先验分布和求解器验证；
5. 主要模型和至少两个基线；
6. 主要指标与 OOD 轴；
7. 算力、数据和时间预算；
8. 预期失败模式和停止规则。

## 最低复现实验

- 三个随机种子；
- 三种训练集规模；
- 一个模型容量消融；
- 一个分辨率迁移实验；
- 两个 OOD 实验；
- 与数值求解器的成本比较；
- 至少五个逐样本可视化，包括失败样本。

## 报告结构

1. 问题与价值；
2. 数学定义；
3. 数据和数值方法；
4. 模型与基线；
5. 统一评估协议；
6. 主要结果；
7. 消融和 OOD；
8. 失败机制；
9. 成本与部署边界；
10. 可复现说明。

## 完成定义

只有当一个新的学习者能够根据 README 在干净环境中生成小数据、训练模型、得到指标并理解其含义时，项目才算完成。
