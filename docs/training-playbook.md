# 训练经验手册

## 1. 先验证数据，再调模型

每个数据集都应保存以下元数据：PDE 公式、定义域、初边值条件、数值求解器、容差、网格、时间步、输入函数分布、随机种子和变量单位。

参考解至少通过一种检查：解析解、网格加密、守恒量、离散 residual 或与另一求解器交叉比较。

## 2. 函数级划分

先按输入函数 realization 划分 train/validation/test，再进行下采样、传感器抽取或多分辨率处理。同一个连续函数的不同离散副本不能跨集合，否则会造成严重泄漏。

## 3. 归一化

- 只使用训练集统计量；
- 不同物理变量分别归一化；
- 坐标统一缩放并记录物理域；
- 推理后反归一化，再计算有物理意义的指标；
- 将 normalizer 参数和 checkpoint 一起保存。

## 4. DeepONet

- 先从固定传感器和全网格查询开始；
- 再尝试随机 query，降低训练时的查询成本；
- 传感器数、位置和 latent dimension 都应做消融；
- branch 输入幅度跨度很大时，优先检查标准化，而不是立刻加深网络；
- trunk 坐标编码不足时，可尝试 Fourier features，但必须作为显式消融。

## 5. FNO

- 模态数不能超过离散网格可表示的频率范围；
- 先观察目标解和误差的频谱，再选择 modes；
- 非周期问题应评估 padding、坐标通道、边界 mask 或硬边界变换；
- 增加 modes 和 width 的作用不同：前者改变频域容量，后者改变通道表示容量；
- 在低分辨率训练、高分辨率测试时，检查训练数据是否真正包含目标高频。

## 6. 优化与记录

Adam/AdamW、约 \(10^{-3}\) 的初始学习率和余弦退火是合理起点，不是领域标准答案。每次运行至少保存：

- 完整配置和随机种子；
- Git commit；
- 数据 manifest 或 hash；
- train/validation 曲线；
- 最优与最终 checkpoint；
- 参数量、训练时间和推理时间；
- 原始逐样本指标，而不仅是平均值。

## 7. 时间演化

单步训练存在 exposure bias。评估必须进入 closed-loop rollout。可以尝试：

- 逐步增加 unroll horizon；
- 在训练中使用自己的预测作为下一步输入；
- 多步损失或谱加权损失；
- 检查守恒量、能谱和稳定时间，而不仅是像素误差。

## 8. 物理损失

总损失通常写成

\[
\mathcal L=\lambda_d\mathcal L_{data}+
\lambda_f\mathcal L_{PDE}+
\lambda_b\mathcal L_{BC}+
\lambda_i\mathcal L_{IC}.
\]

各项量纲和梯度规模可能相差几个数量级。需要同时记录各损失及其梯度，而不是只观察总和。Residual 的导数可来自自动微分、有限差分或谱微分；每种方法都有不同误差和几何限制。

## 9. 常见失败顺序

遇到模型失败时，按以下顺序排查：

1. 数值标签和边界是否正确；
2. 张量轴、坐标、单位和归一化是否一致；
3. train/test 是否泄漏；
4. 损失聚合是否按样本计算；
5. 学习率、梯度和数值精度是否稳定；
6. 数据分布是否覆盖测试输入；
7. 最后才是模型容量是否不足。
