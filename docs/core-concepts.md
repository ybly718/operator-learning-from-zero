# 核心概念与模型选择

## 1. 什么是算子学习

给定两个函数空间 \(\mathcal A\) 和 \(\mathcal U\)，算子学习寻找参数化映射

\[
\mathcal G_\theta:\mathcal A\rightarrow\mathcal U,
\]

使其逼近未知或昂贵的真实算子 \(\mathcal G^\dagger\)。对 PDE 而言，输入可以是系数场、forcing、初值、边界条件或几何，输出通常是解函数。

训练数据不是普通的点对，而是函数对：

\[
\{(a_i(\cdot),u_i(\cdot))\}_{i=1}^{N},\qquad
u_i=\mathcal G^\dagger(a_i).
\]

计算机只能看到这些函数的有限采样。因此实践中同时存在函数分布、传感器/网格、数值真值和学习模型四层近似。

## 2. 与邻近方法的区别

### 普通监督学习

普通网络通常学习固定维向量之间的映射。将每个网格场简单展平成向量可以工作，但模型参数和表示往往绑定于特定网格。

### PINN

PINN 通常为一个给定 PDE 实例寻找解函数 \(u_\theta(x)\)。算子学习训练一次，目标是在一族不同输入函数或参数上复用。PINO 和 physics-informed DeepONet 将两种思想结合起来。

### 降阶模型

POD/PCA 等方法先找低维线性子空间，再学习坐标映射。它们是不可缺少的强基线，而不是应该被省略的“旧方法”。

### 传统数值方法

数值求解器解决一个实例，通常具有明确的收敛与误差理论。神经算子使用昂贵的前期数据生成和训练，换取大量后续查询的快速近似。

## 3. 三类核心架构

### DeepONet

DeepONet 使用 branch net 从输入函数的传感器值提取系数，使用 trunk net 表示输出坐标相关的基函数：

\[
\mathcal G_\theta(a)(y)=\sum_{k=1}^{p}b_k(a(x_1),\ldots,a(x_m))t_k(y)+b_0.
\]

适合：输出需要在任意查询点求值、输入传感器结构清晰的问题。

主要限制：固定传感器可能丢失输入信息；高维输出查询的计算量可能较大。

### FNO

FNO 在频域参数化全局卷积核：

\[
v_{l+1}(x)=\sigma\left(W_lv_l(x)+
\mathcal F^{-1}(R_l\,\mathcal Fv_l)(x)\right).
\]

适合：规则网格、大量场到场样本、具有明显全局和低频结构的问题。

主要限制：FFT 偏好规则网格和周期结构；谱截断、混叠和边界处理必须认真检查。

### 几何/attention 神经算子

GNO、GINO、Geo-FNO 和 operator transformers 用图积分、潜在规则网格、坐标变换或注意力处理非规则网格和变化几何。

适合：点云、有限元网格、变化几何和多输入物理量。

主要限制：几何编码、邻域或 tokenization 本身会引入新的离散误差；模型能处理新网格不代表能泛化到新拓扑。

## 4. 五个容易混淆的概念

1. **通用逼近**：模型类在理想条件下存在足够好的参数。
2. **可训练性**：优化器能否在有限算力下找到这些参数。
3. **离散化无关性**：同一参数化是否可以在不同离散上定义或运行。
4. **分辨率泛化**：换网格后误差是否仍然小。
5. **分布外泛化**：输入函数、参数、边界、几何或方程改变后是否仍有效。

前一个性质不会自动推出后一个性质。

## 5. 什么时候值得使用

优先考虑算子学习：

- 同一类问题需要被求解成千上万次；
- 单次高精度求解昂贵，但可离线生成代表性数据；
- 允许可量化的近似误差；
- 输入分布和部署范围可以相对明确地描述。

谨慎或暂不使用：

- 只需要求解一个实例；
- 训练分布无法覆盖未来输入；
- 需要严格守恒、认证误差或安全保证；
- 高质量标签成本高于未来全部数值求解成本。
