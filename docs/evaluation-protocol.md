# 统一评估协议

## 1. 主要指标

默认主要指标为逐样本相对 L2 后宏平均：

\[
\frac{1}{N}\sum_{i=1}^{N}
\frac{\|\hat u_i-u_i\|_2}{\|u_i\|_2+\epsilon}.
\]

不要用“先把所有样本拼接再计算一次 L2”替代它；两种聚合会给不同幅值样本不同权重。

## 2. 辅助指标

根据问题至少选择两项：

- 反归一化后的 RMSE/MAE；
- H1 或梯度误差；
- 边界与内部区域误差；
- 频段误差或能谱误差；
- 守恒量、通量、阻力等物理量误差；
- 长期 rollout error 和稳定时间。

## 3. 最低测试矩阵

### 分布内

独立输入函数、相同参数范围、相同几何和求解精度。

### 分辨率

分别在低于、等于和高于训练分辨率的网格上评估，同时记录重采样规则和物理频率范围。

### 分布外

至少选择两条独立轴：

- 系数或物理参数范围；
- 输入函数相关长度/频率；
- 边界条件或 forcing；
- 几何或拓扑；
- 时间跨度或时间步；
- 未见方程。

### 成本

报告数据生成、训练、单次推理和传统求解器单次求解的时间。给出近似盈亏平衡查询次数：

\[
N_{break-even}\approx
\frac{T_{data}+T_{train}}{T_{solver}-T_{inference}}.
\]

## 4. 公平比较检查表

- 相同训练/验证/测试函数 ID；
- 相同物理输入信息；
- 相同归一化和指标；
- 调参预算可比；
- 参数量和计算量已报告；
- 至少三个随机种子；
- 展示完整均值与离散程度；
- 不只选择对某个模型最有利的单一指标。

## 5. 结果声明模板

合格的结论应形如：

> 在指定输入函数分布、网格范围和训练预算下，模型 A 在主要相对 L2 指标上优于模型 B；但在高频 OOD 或长期 rollout 上优势消失。因此结论仅适用于已测试的部署范围。

不要写成：

> 模型 A 学会了该 PDE，并且具有分辨率无关性。
