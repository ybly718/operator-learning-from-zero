# 12 周教案总览

这套课程默认学习者掌握基础微积分、线性代数和 Python，但不要求已有 PDE、泛函分析或科学机器学习经验。每周建议投入 8–12 小时；数学基础较弱时，可以把前两周扩展为四周。

## 教学闭环

每周遵循同一结构：

1. **问题驱动**：先说明这一周要解决什么困难；
2. **最小理论**：只学习完成任务所必需的数学和模型知识；
3. **可执行实验**：得到可复现的数字结果；
4. **诊断练习**：主动制造一种失败并解释原因；
5. **验收标准**：用证据判断是否真正掌握。

## 周计划

| 周次 | 主题 | 必须交付的证据 |
|---:|---|---|
| 1 | 从函数拟合到算子学习 | 问题定义卡和三类适用/不适用案例 |
| 2 | PDE、函数空间与数值真值 | Poisson 求解器验证和网格收敛表 |
| 3 | DeepONet | branch/trunk 维度推导和训练曲线 |
| 4 | FNO | 谱卷积实现、模态消融和频谱图 |
| 5 | 公平模型比较 | 统一数据、预算、指标下的对比表 |
| 6 | 分辨率与分布外泛化 | 至少两类 OOD 测试和失败分析 |
| 7 | 时间依赖算子 | one-step 与 rollout 误差曲线 |
| 8 | 物理约束 | 数据损失与 PDE 残差的权衡实验 |
| 9 | 不规则几何 | 模型选择说明和几何编码原型 |
| 10 | 多方程预训练 | 三篇 foundation model 的结构对照 |
| 11 | 研究问题设计 | 预注册式实验计划和停止规则 |
| 12 | 结课项目 | 代码、结果、失败分析和复现报告 |

详细内容位于 [weeks](weeks/) 目录。

## 评分标准

- 理论解释：20%
- 数值真值和数据质量：20%
- 模型实现与测试：20%
- 评估严谨性：25%
- 复现性与研究表达：15%

通过要求不是“模型达到最低误差”，而是学习者能够说明：模型学到了什么、在哪些分布上有效、何时失效，以及结果是否值得替代传统求解器。
