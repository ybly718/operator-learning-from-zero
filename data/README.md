# 数据约定

仓库默认不提交大型数据文件。第一个可运行任务由代码即时生成：

- 输入：一维正系数场 a(x)；
- 方程：-(a(x)u'(x))' = 1；
- 边界：u(0) = u(1) = 0；
- 输出：同一网格上的解场 u(x)。

## 公平比较原则

1. 先生成完整样本，再按“函数样本”划分 train/validation/test，不能把同一条函数的不同坐标点拆到不同集合。
2. DeepONet 和 FNO 必须读取同一个数据划分、随机种子和预算。
3. 所有归一化统计量只能在训练集上估计。
4. 测试集至少同时报告平均相对 L2、边界误差和频谱误差。
5. 分辨率迁移与分布外测试必须单列，不与同分布测试混合。

## 外部数据目录

需要使用 PDEBench、PDEArena、The Well 等数据集时，在本目录建立以下结构，并保持原始文件不进入 Git：

    data/
      raw/
      processed/
      manifests/

每次实验应在 manifests 中记录数据来源、许可、下载日期、校验和、划分策略和预处理版本。
